# Raghav Nanda Portfolio — GitHub Pages Export

This folder is a static, GitHub Pages–ready build of the portfolio.

## Upload with GitHub’s website

1. Create a new public GitHub repository.
2. Extract the ZIP and upload **all extracted files and folders** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then click **Save**.

GitHub will provide the live URL after deployment finishes. Keep the `assets` folder and `eyes-moving.json` beside `index.html`; the site needs them for styling, scripts and the interactive head.
